# Social Play — brand files

| File | Use |
|---|---|
| `logo-animated.svg` | Animated logo (watch face → dots merge → light snake → star burst, 12 s loop). Website hero, presentations. |
| `logo-icon.svg` | Static logo, rounded square with transparent corners. General use. |
| `app-icon.svg` | Full-bleed square source for app stores (store applies its own rounding). |
| `favicon.svg`, `favicon.ico`, `favicon-16.png`, `favicon-32.png` | Browser tab icons (bolder strokes for tiny sizes). |
| `apple-touch-icon.png` | 180×180, iOS home screen. |
| `icon-192.png`, `icon-512.png` | Web app manifest icons. |
| `icon-maskable-512.png` | Android adaptive / maskable icon (content inside the safe zone). |
| `app-store-1024.png` | 1024×1024, Apple App Store (no transparency). |
| `play-store-512.png` | 512×512, Google Play Store. |

Colours: night `#14111F`, body `#221D35`, face `#0E0C16`, mint `#5FD8B4`, coral `#FF6B4A`, violet `#A79BFF`, paper `#F7F2E8`.
